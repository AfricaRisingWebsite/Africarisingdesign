# Uploading the Africa Rising Investments preview

Repository: https://github.com/AfricaRisingWebsite/Africarisingdesign

## 1. Upload the website

1. Download and extract `Africarisingdesign-github-pages.zip`.
2. Open the repository and choose **Add file → Upload files**.
3. Upload everything inside the extracted folder. `index.html`, `styles.css`, `script.js`, `robots.txt` and the `assets` folder must appear at the repository root.
4. In the commit box, enter `Add Africa Rising Investments website prototype`.
5. Choose **Commit changes**.

## 2. Turn on the public preview

1. Open **Settings → Pages** in the repository.
2. Under **Build and deployment**, choose **Deploy from a branch**.
3. Select **main** and **/(root)**.
4. Choose **Save** and wait for the deployment to finish.

## 3. Share the preview

The client-review link is:

https://africarisingwebsite.github.io/Africarisingdesign/

The site is public to anyone with the link but asks search engines not to index it. Do not connect `africa.or.ke` or change DNS until the client approves the prototype and the existing website, DNS and email records are backed up.
